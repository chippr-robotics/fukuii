- **The hive adapter maps BPO3 to BPO5 (B-456).** `hive/fukuii/fukuii.sh` read only `HIVE_BPO1/2_*`, so a hive
  simulator that schedules BPO3..BPO5 ran fukuii without those forks: a fork id short of them and the wrong blob
  parameters after BPO2. It now maps `HIVE_BPO3..5_TIMESTAMP` and
  `HIVE_BPO3..5_BLOB_{TARGET,MAX,BASE_FEE_UPDATE_FRACTION}` as hive's `clients/go-ethereum/mapper.jq` does, and the
  hive chain conf falls back to that mapper's values (target 9, max 14, fraction 8832827) when a simulator sets the
  timestamp alone.
