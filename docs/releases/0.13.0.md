# 0.13.0 (in preparation)

Promotion of `staging` (0.12.x series) to `main`. This file collects what an operator must know before upgrading; the
full detail is in the [changelog](https://github.com/chippr-robotics/fukuii/blob/main/CHANGELOG.md).

## Read before upgrading

- **A plaintext listener on a non-loopback interface refuses the start (spec 030 FR-018, FR-019).** JSON-RPC HTTP,
  WebSocket, the Engine API and the metrics endpoint each need `tls.enabled = true`, or
  `allow-insecure-bind = true` to accept plaintext deliberately, when their `interface` is not loopback (`0.0.0.0`,
  `::`, a LAN address or a name resolving to one). The refusal names both keys; the opt-out logs a WARN line at every
  start. **The metrics endpoint now binds `localhost` by default** (it bound every interface): a Prometheus server on
  another host needs `fukuii.metrics.interface` set. See
  [the migration section of the TLS runbook](../runbooks/tls-operations.md#migration).
