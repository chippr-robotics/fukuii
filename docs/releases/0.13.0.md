# 0.13.0: zero-trust listeners, SNAP that finishes, Hive as gates

Promotion of `staging` (0.12.x series, through 0.12.21x) to `main`. 0.13.0 brings no hard fork and changes no fork
schedule on any shipped chain, so nothing in it has to be installed by a fixed date. The full detail is in the
[changelog](https://github.com/chippr-robotics/fukuii/blob/main/CHANGELOG.md).

## Read before upgrading

- **A plaintext listener on a non-loopback interface refuses the start (spec 030 FR-018, FR-019).**
  - This covers JSON-RPC HTTP, WebSocket, the Engine API and the metrics endpoint.
  - Each one needs `tls.enabled = true`, or `allow-insecure-bind = true` to accept plaintext deliberately, when its
    `interface` is not loopback: `0.0.0.0`, `::`, a LAN address, or a name resolving to one.
  - The refusal names both keys. The opt-out logs a WARN line at every start.
  - **The metrics endpoint now binds `localhost` by default**; it used to bind every interface. A Prometheus server on
    another host needs `fukuii.metrics.interface` set.
  - See [the migration section of the TLS runbook](../runbooks/tls-operations.md#migration).
- **HTTP and WebSocket JSON-RPC serve only `eth`, `net`, `web3` and `fukuii` by default, as go-ethereum does.**
  - Each transport has its own key: `network.rpc.http.apis`, `ws.apis` and `ipc.apis`. Each falls back to
    `network.rpc.apis`.
  - An operator who used `personal`, `debug`, `admin` or `qa` over HTTP or WS must list them there.
  - An unknown namespace name stops the start and names its key.
- **The WebSocket server accepts browser connections only from allowed origins** (`ws.allowed-origins`, default
  localhost).
  - Clients that send no `Origin` header (CLIs, libraries, consensus clients) are unaffected.
- **On ETH, Sepolia, Hoodi, Ephemery and Platåberget, the Engine API is on by default**, on `localhost:8551`.
  - With no `jwt-secret-path`, the secret is `<datadir>/jwt.hex`. It is created at first start with mode 0600, as
    go-ethereum does.
  - A secret file readable by its group or by others stops the start.
  - ETC, Mordor and Gorgoroth are unchanged: the Engine API stays off.
- **The sample TLS keystore is no longer shipped.**
  - Generate a per-deployment certificate with `tls/gen-cert.sh` (it needs `openssl`).
  - A config that points at the old `tls/fukuiiCA.p12` must point at the generated files.
- **`eth_call` returns an error for a frame that fails, as go-ethereum does.**
  - Out of gas, an invalid opcode or a stack error used to come back as a successful `"0x"`. It is now `-32000` with
    geth's message.
  - A revert is unchanged.
- **Grafana: some metrics are counters now, and are exposed with `_total`** (B-200).
  - The Engine API status counts are now `app_engine_*_{valid,syncing,invalid,accepted}_total`, along with
    `app_engine_auth_failures_total` and `app_engine_import_path_invalid_reports_total`.
  - The RocksDB block-cache and index-filter hit/miss counts gain `_total` too.
  - The shipped dashboards are updated. Update any scrape rules or alerts of your own.
- **Give the node time to close its database on stop** (B-444).
  - A stop can take up to about 2 minutes before RocksDB closes.
  - The shipped compose files and runbook units now allow 180 s. Docker's default is 10 s and systemd's is 90 s.
  - Set at least `stop_grace_period: 180s` or `TimeoutStopSec=180` in your own units.
- **Scala 3.9.0 LTS.** Projects that consume the published `bytes`, `crypto`, `rlp`, `scalanet` or `scalanet-discovery`
  modules must rebuild on Scala 3.9. Node behaviour is unchanged.
- **Security: CVE-2026-114938 ("Java4Shell") is mitigated** (B-418).
  - The images are pinned to `eclipse-temurin:25.0.5.1_2`.
  - The launchers add `-XX:DisableIntrinsic=_base64_decodeBlock`, which covers an install still on an affected JDK.
    Upgrade that JDK anyway.

## What's new

- **SNAP healing finishes on a live chain** (spec 022).
  - Healing used to prove the state complete by walking every stored trie node: about 17 h on Sepolia, and 16–20 h on
    ETC mainnet. Its result went stale with every pivot move.
  - A healed node now reaches disk only once its whole subtree is present, so healing is done when nothing is pending,
    held or excluded.
  - The full walk is now a background audit after the hand-off.
- **Zero-trust listeners** (spec 030):
  - mutual TLS on JSON-RPC, with client-certificate identities that select namespaces;
  - TLS on the Engine API and metrics;
  - TLS material and identity rules reload without a restart;
  - one outbound TLS factory;
  - runtime edits to the P2P node allowlist (`admin_addNodesToAllowlist`).
- **Hive suites are required gates.** smoke-genesis, smoke-network, sync, engine and consume-rlp, plus EEST Amsterdam,
  must be green to merge. Each was promoted on a green run on `main` that met its minimum test count.
- **ETH chains run on Windows** (B-151).
  - The EIP-2537 BLS12-381 precompiles now have a supranational blst backend.
  - It matches eth_pairings and gnark byte for byte on all 3,636 corpus inputs.
  - Linux and macOS keep eth_pairings. `fukuii.vm.bls12-381-backend` chooses the backend.
- **The `--tui` operator dashboard** (specs 027 and 029):
  - views and alerts;
  - a log tail;
  - peers with their clients and reliability scores;
  - the txpool;
  - a consensus-layer panel on ETH and a mining panel on ETC;
  - an Ops view that can act on the node.
- **Built-in networks:**
  - Hoodi (`fukuii hoodi`).
  - Ephemery needs no preparation step: the current iteration is in the jar, and the node exits 75 at its reset so that
    a supervisor restarts it.
- **ETC checkpoint archive** (B-379): a fresh ETC node can start from block 25,808,558 instead of genesis. See
  `fukuii.sync.checkpoint-sync-url` in the changelog.
- **RPC parity with go-ethereum:**
  - `safe` and `finalized` state reads work on PoS.
  - EIP-1898 `requireCanonical` is honoured.
  - `newHeads` and `logs` follow the Engine API's fork choice.
  - `eth_simulateV1` and the VM error texts follow geth v1.17.9.

## Fixes worth knowing

- **Other clients can snap-sync storage from fukuii again** (B-566). A multi-contract `StorageRanges` reply carried the
  wrong contract's proof, so go-ethereum and Nethermind rejected it.
- **Pruning no longer deletes a trie node it cannot prove dead** (#1692). This matters for ETC and Mordor datadirs
  filled by SNAP, a checkpoint or an old fast sync.
- **A missing BLS12-381 or KZG native library no longer forks the node off the network** (B-135). The node refuses to
  start, or halts, instead of computing a wrong result.
- **Log volume:** routine events about individual peers are DEBUG now. One `Network [60s]` INFO line sums them.
- **Logging:** node start no longer prints about 150 logback status lines, and the JDK 25 `Unsafe` warning no longer
  draws over the `--tui` first frame.

## Validation

- **Tests:** the unit, integration and ethereum/tests suites pass in CI on the release candidate, as do the required
  Hive gates and EEST Amsterdam. The promotion PR also runs the full Hive pass (`hive-full`).
- **Live gates:** the spec 018 unified-state-layout gates (ETC mainnet EG-12, Mordor, and Sepolia on a GCP VM) ran on
  earlier 0.12.x builds. They run again on 0.13.0 itself, and their results are reported in the backlog (B-068,
  B-393).
- **Not in this release:** the fixed-width UInt256 (spec 021) moved to 0.14.0. The unified state layout (spec 018) is
  still behind its `fukuii.state.path-live` guard, pending its C7 exit gate.
