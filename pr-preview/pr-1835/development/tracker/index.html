    How to claim¶

    Claim before you start

    The protocol is .claude/agent-protocols/backlog-tracker.md in the repository. Set your node name once per host, then claim, keep the status current, and close the item when its PR merges:

    export FUKUII_NODE=fukuii-fc          # or dev-node, cloud-<name>
python3 -I scripts/backlog/backlog.py list
python3 -I scripts/backlog/backlog.py claim B-012 --agent forge --branch fix/my-branch
python3 -I scripts/backlog/backlog.py status B-012 review --pr 1750
python3 -I scripts/backlog/backlog.py done B-012 --pr 1750

    A rejected push means someone moved first: the CLI fetches, re-checks and retries. A PR body names its item with a Backlog: B-012 line. People may also edit backlog.yaml in the GitHub web UI.
