# Spec 018 Track C, C4b part 3 (T140): where the best block and the index of blocks by number are written, and why each
# writer cannot move the head alone on the unified state layout (data-model 5.1, I1: the state anchor and the best
# block are one block, and move together or not at all).
#
# Checked by scripts/check-head-writers.sh, which says what each entry point is. Run it with --inventory to see what
# the tree holds.
#
#   entry-point  count  file  reason
#
# The count is exact: more uses fail the check, and so do fewer. A NEW line is a writer of the head, and says which of
# these holds, in its first word:
#   MOVE      it moves the head with the state: a block's own commit, a move of the head, the genesis commit
#   REFUSED   it refuses on the unified layout (an IllegalStateException), so it cannot move the head alone there
#   DEF       the writer's own definition, or what builds a batch and writes nothing
#   HASH      it runs on the hash layout only: the unified layout takes another branch first
#   PRE       it runs before the state has an anchor (SNAP, a checkpoint import, the pivot): refused on the unified
#             layout until C5a/C5c (ConfigValidator refuses SNAP and mining there; sync is not started there)
#   START     a repair at start, before any writer: part 4's reconciliation takes it over
#   C4D/C4E   a writer the named slice routes through a move; not reached on the unified layout before it
